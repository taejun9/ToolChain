# Workflow engine

그래프를 검증한 후 Kahn 알고리즘으로 위상 정렬한다. 기본은 순차 실행이며 워크플로 설정에 따라 의존성이 완료된 노드를 최대 4개까지 실행한다. 실패하면 하위 의존 노드를 취소한다. 독립 경로는 계속 실행할 수 있다. AbortSignal로 실행을 중단하며 각 노드의 상태와 처리 시간을 보고한다.

조건 노드는 입력 텍스트를 지정한 문자열과 비교해 match 또는 otherwise 출력만 반환한다. 활성화되지 않은 경로의 필수 입력을 기다리는 노드는 건너뛴다. 스킵은 실행 실패와 별개로 기록한다. 로그의 시간 오프셋은 실행 시작점을 기준으로 하며, 내보낸 JSON에는 노드 ID, 도구 ID, 상태, 소요 시간, 타입, 바이트 수, 오류 코드만 포함된다.
