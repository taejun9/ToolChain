# ToolChain 후속 단계

1. PDF 병합·페이지 추출 및 다중 파일 ZIP 압축·해제를 실제 파일과 Worker에서 검증한다.
2. 조건에 따라 출력 포트를 선택하고, 독립 DAG 노드는 제한된 동시성으로 실행한다. 직렬 모드를 유지하고 기존 워크플로를 검증한다.
3. 디버거에 실패·스킵 원인, 타임라인 및 로그 내보내기를 제공한다. 원본은 로그에 포함하지 않는다.
4. 백엔드 없는 공유 링크를 검증 후 열고 복제하는 흐름을 제공한다. 실행 입력은 공유 범위에서 제외한다.
5. 단위·브라우저 테스트, 빌드 및 Wrangler 로컬 확인을 마친다.

원격 CI와 승인된 Cloudflare 배포는 [운영 릴리스 계획](../active/plan-003-release.md)에서 추적한다.
