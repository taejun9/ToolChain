# 후속 구현 검토

- PDF의 병합 순서와 페이지 추출 결과를 실제 파일의 페이지 크기로 검사했다. ZIP은 텍스트와 바이너리 왕복 및 위험 경로 거부를 확인했다.
- 스케줄러는 준비된 노드를 제한된 슬롯에 배정하고, 다른 분기가 끝날 때까지 독립적인 후속 노드를 대기시키지 않는다. 기존 단일 실행 순서를 유지한다.
- 공유 링크는 새 브라우저 컨텍스트에서 검증, 실행, 저장할 수 있다. 실행 입력은 링크에 포함되지 않는다. 진단 내보내기에도 원본 값을 기록하지 않는다.
- PDF와 ZIP 라이브러리는 Worker에서 지연 로드한다. 배포 빌드에서 관련 라이선스를 제공한다.
