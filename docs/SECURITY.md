# Security

로컬 파일은 File/Blob으로 처리한다. 가져온 문서는 크기, 구조, 버전 및 그래프를 검증한다. Vue 텍스트 바인딩과 CSP로 임의 HTML 삽입을 제한한다. 로그에는 원본 대신 포트 타입, 크기 및 오류 코드만 저장한다.

배포 CSP는 기본적으로 외부 리소스와 JavaScript 평가를 차단한다. WebP 인코딩을 수행하는 Worker 응답에만 `wasm-unsafe-eval`을 허용한다. 이미지에는 형식 시그니처를 확인하고, 변환에는 브라우저 디코더를 사용한다. 원본이나 실행 결과를 저장소로 보내는 엔드포인트가 없다. 해시 정적 자산은 캐싱하고 HTML과 검색 메타데이터는 재검증한다.

잠금 파일의 런타임 의존성 라이선스 메타데이터는 MIT, Apache-2.0, ISC, BSD-2-Clause, BSD-3-Clause, 0BSD 및 MPL-2.0이다. MPL-2.0 항목은 CSS 빌드에 사용하는 Lightning CSS와 플랫폼 바이너리다. WebP에 포함되는 libwebp 라이선스는 정적 빌드에 함께 제공한다.

PDF는 파일 시그니처와 파서로 검사하고 암호화된 입력을 거부한다. ZIP은 항목 수와 압축 해제 예상 크기를 제한하고, 상위 경로·절대 경로·중복 다운로드 이름을 거부한다. 공유 정의는 서버 요청에 포함되지 않는 URL 프래그먼트로 전달된다. 링크를 가진 사람은 이름과 도구 설정을 볼 수 있다.
