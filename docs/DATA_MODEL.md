# Data model

Workflow v1은 ID, 이름, 설명, 시간, 노드와 에지를 갖는다. 노드는 도구 ID와 버전, 좌표, JSON 설정을 갖는다. 에지는 출발·도착 노드와 포트를 참조한다. 파일 입력과 실행 결과는 런타임 데이터로 분리한다. IndexedDB 스키마 버전과 워크플로 문서 버전은 별도로 관리한다.

Dexie에 필드를 추가할 때는 다음 `db.version(n).stores(...).upgrade(...)` 단계에서 기존 레코드를 변환한다. 워크플로 내보내기 형식이 바뀔 때는 문서 `schemaVersion`에 해당하는 변환을 적용한 뒤 새 스키마를 검증한다. 현재는 버전 1만 지원하며 다른 버전의 문서는 명시적인 오류로 표시한다. 가져오기는 새 ID를 발급하므로 같은 ID의 기존 워크플로를 덮어쓰지 않는다.
